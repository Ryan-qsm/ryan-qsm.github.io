# 示例课程：文章格式说明

> 这是一篇示例文档，展示一篇文章的基本写法。以后新建文章时，复制这个文件再修改即可。

## 一、文章标题

每篇文章的第一行用 `# 标题` 的格式，只写一个标题。

## 二、正文

正文直接写文字即可。想分段时，中间空一行。

- 想列清单时，每行开头写一个短横线
- 比如：第一点
- 比如：第二点

想加粗文字时，用两个星号包起来，例如 **重点内容**。

想放链接时，写成 `[链接文字](网址)`，例如 [MkDocs 官网](https://www.mkdocs.org/)。

## 三、代码

需要展示代码时，用三个反引号包起来：

```python
print("你好，世界")
```

## 四、小结

写完后保存文件，浏览器里的预览会自动刷新。
